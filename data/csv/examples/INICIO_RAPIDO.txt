DESCRIPCIÓN RÁPIDA
================================================================================

Este directorio contiene 6 archivos CSV de ejemplo listos para importar a la
base de datos del Sistema Agro Sentinel. Incluye datos de prueba para:

  • Artículos (cultivos)
  • Centros de costo (ranchos)
  • Producciones
  • Zonas de producción
  • Asignaciones de zonas
  • Monitoreo de escenas IA

================================================================================
INICIO RÁPIDO (3 PASOS)
================================================================================

OPCIÓN 1: Script Bash (Linux/Mac)
----------------------------------
1. Ir al proyecto:
   cd /xampp/htdocs/WEB/clientes/DRH/go-agro-sentinel-worker

2. Ejecutar importación:
   chmod +x scripts/import-csv.sh
   ./scripts/import-csv.sh import-all

3. Verificar:
   mysql -h localhost -u admin -padmin agro -e "SELECT COUNT(*) FROM articulos;"


OPCIÓN 2: PowerShell (Windows)
-------------------------------
1. Abrir PowerShell

2. Navegar al proyecto:
   cd C:\xampp\htdocs\WEB\clientes\DRH\go-agro-sentinel-worker

3. Ejecutar importación:
   .\scripts\import-csv.ps1 -Comando ImportAll

4. Verificar:
   mysql -h localhost -u admin -padmin agro -e "SELECT COUNT(*) FROM articulos;"


OPCIÓN 3: SQL Directo (MySQL)
------------------------------
1. Abrir MySQL Workbench o línea de comandos

2. Ejecutar:
   mysql -h localhost -u admin -padmin agro < scripts/import-from-csv.sql

3. Los datos se importarán automáticamente con validaciones

VALIDACIONES
================================================================================

Después de importar, verificar que los datos están correctos:

OPCIÓN 1: Con script Bash
  ./scripts/import-csv.sh list-tables

OPCIÓN 2: Con MySQL
  mysql -h localhost -u admin -padmin agro << EOF
  SELECT 'articulos' as tabla, COUNT(*) FROM articulos
  UNION ALL SELECT 'centros_costos', COUNT(*) FROM centros_costos
  UNION ALL SELECT 'producciones', COUNT(*) FROM producciones
  UNION ALL SELECT 'zonas_producciones', COUNT(*) FROM zonas_producciones
  UNION ALL SELECT 'asignaciones_zonas_producciones', COUNT(*) FROM asignaciones_zonas_producciones
  UNION ALL SELECT 's3_monitoring_escena_ia_resumen', COUNT(*) FROM s3_monitoring_escena_ia_resumen;
  EOF

Resultado esperado: Cada tabla debe mostrar el número correcto de registros

================================================================================
ESTRUCTURA DE CAMPOS
================================================================================

ARTICULOS
---------
articulo_id (INT)      - ID único del artículo
nombre (VARCHAR)       - Nombre del cultivo (requerido)
variedad (VARCHAR)     - Variedad específica (opcional)

Ejemplo:
1,Lechuga,Latina


CENTROS_COSTOS
---------------
centro_costo_id (INT)  - ID único del rancho
nombre (VARCHAR)       - Nombre del rancho (requerido)

Ejemplo:
1,Rancho Los Andes


PRODUCCIONES
------------
folio (VARCHAR)        - ID único de producción
articulo_id (INT)      - ID del artículo
fecha (DATE)           - Fecha inicio (YYYY-MM-DD)
hora (TIME)            - Hora inicio (HH:MM:SS)
fecha_cierre (DATE)    - Fecha cierre (opcional)
hora_cierre (TIME)     - Hora cierre (opcional)
usuario (VARCHAR)      - Usuario que registró
estatus (CHAR)         - N=Normal, T=Terminada, C=Cancelada
aplicado (CHAR)        - S=Sí, N=No
cantidad (DECIMAL)     - Área en hectáreas
centro_costo_id (INT)  - ID del rancho
monitoring (TINYINT)   - 0=No, 1=Sí

Ejemplo:
CSJ2601-17-A,1,2026-06-03,08:30:00,,,"admin",N,S,2.50,1,1


ZONAS_PRODUCCIONES
------------------
zona_produccion_id (INT)  - ID única de zona
nombre (VARCHAR)          - Nombre completo
nombre_corto (VARCHAR)    - Abreviatura (ej: ZNA)
estatus (CHAR)            - P=Producción, I=Inactiva
area (DECIMAL)            - Área en hectáreas
centro_costo_id (INT)     - ID del rancho
poligono (TEXT)           - Coordenadas GeoJSON

Ejemplo:
1,Zona Norte Los Andes,ZNA,P,5.50,1,"[[21.10535, -100.93089], [21.10535, -100.92730]]"


ASIGNACIONES_ZONAS_PRODUCCIONES
--------------------------------
asignacion_zona_prod_id (INT)  - ID única de asignación
produccion_id (INT)            - ID de producción
zona_produccion_id (INT)       - ID de zona
tipo_asignacion (CHAR)         - T=Total, P=Parcial
area (DECIMAL)                 - Área asignada
poligono (TEXT)                - Coordenadas GeoJSON

Ejemplo:
1,1,1,P,2.50,"[[21.10535, -100.93089], [21.10535, -100.92730]]"


S3_MONITORING_ESCENA_IA_RESUMEN
--------------------------------
s3_monitoring_escena_id (BIGINT)  - ID de escena
estado_clave (VARCHAR)            - normal, alerta, crítico
estado_general (VARCHAR)          - Estado general
riesgo_nivel (VARCHAR)            - bajo, medio, alto
riesgo_motivo (TEXT)              - Descripción del riesgo
fecha_analisis (DATETIME)         - Fecha del análisis
json_original (LONGTEXT)          - JSON de respuesta IA

Ejemplo:
1001,normal,OK,bajo,Sin anomalías,2026-06-03 10:30:00,"{""status"": ""normal""}"

ERRORES COMUNES Y SOLUCIONES
================================================================================

ERROR: "Can't find file"
SOLUCIÓN: Usar ruta absoluta en lugar de relativa

ERROR: "Access denied; you need FILE privilege"
SOLUCIÓN: Ejecutar en MySQL:
         GRANT FILE ON *.* TO 'admin'@'localhost';
         FLUSH PRIVILEGES;

ERROR: "Loading local data is disabled"
SOLUCIÓN: Ejecutar en MySQL:
         SET GLOBAL local_infile = 1;

ERROR: "Duplicate entry"
SOLUCIÓN: Limpiar tabla antes:
         DELETE FROM tabla;
         ALTER TABLE tabla AUTO_INCREMENT = 1;

ERROR: "Foreign key constraint fails"
SOLUCIÓN: Importar en orden correcto:
         1. articulos
         2. centros_costos
         3. zonas_producciones
         4. producciones
         5. asignaciones_zonas_producciones
         6. s3_monitoring_escena_ia_resumen

ERROR: "Incorrect date value"
SOLUCIÓN: Usar formato YYYY-MM-DD (ej: 2026-06-03, no 03/06/2026)
