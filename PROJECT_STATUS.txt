================================================================================
                      HOW TO USE
================================================================================

Quick Start:
  1. cd go-agro-sentinel-worker
  2. docker-compose up
  3. curl http://localhost:6000/docs

Start Services:
  API:    go run cmd/api/main.go --config configs/config.example.yaml
  Worker: go run cmd/worker/main.go --config configs/config.example.yaml
  Sync:   go run cmd/sync/main.go --config configs/config.example.yaml

Import Data:
  CSV:       ./scripts/import_csv.sh data/csv/examples/productions.csv
  DynamoDB:  go run cmd/dynamodb_importer/main.go --input data/dynamodb/examples/

Query API:
  Health:    curl http://localhost:6000/health
  Indices:   curl http://localhost:6000/api/v1/scenes/{id}/indices
  History:   curl http://localhost:6000/api/v1/productions/{id}/historical-chain
  Deps:      curl http://localhost:6000/health/dependencies
