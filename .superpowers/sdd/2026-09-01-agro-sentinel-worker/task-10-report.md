## Concerns
- Percentiles are a histogram-bucket-midpoint approximation, not exact — acceptable per brief ("approximate from the statistics").
- `CalculateIndexStatistics` assumes raw index rasters (`<indexType>_raw.tif`) already exist next to multiband.tif, as produced by `GenerateIndex` in indices.go — not generated by this function itself.
- gdalinfo JSON stats field name assumed as `"stats"` (matching real gdalinfo output); not verified against a live GDAL binary since GDAL runs only as an external process and is mocked in tests.
