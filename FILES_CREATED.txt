COMANDOS RÁPIDOS:
════════════════════════════════════════════════════════════════════════════

Setup Automático (Recomendado):
  Linux/Mac:   bash scripts/setup-local-env.sh
  Windows:     .\scripts\setup-local-env.ps1

Ejecutar Tests:
  bash scripts/test-sync-flow.sh

Ver Logs en Vivo:
  docker-compose logs -f sync

Verificar Status:
  docker-compose ps

Conectar a MySQL:
  mysql -h 127.0.0.1 -P 3309 -u root -proot agro

Verificar DynamoDB:
  aws dynamodb list-tables \
    --endpoint-url http://localhost:4566 --region us-east-1

NOTAS IMPORTANTES:
════════════════════════════════════════════════════════════════════════════

1. Docker debe estar instalado y corriendo
2. Si está en Windows, usar PowerShell para scripts .ps1
3. Si está en Linux/Mac, usar bash para scripts .sh
